# TaskFlow 🚀

TaskFlow — это современный REST API для управления задачами. Проект демонстрирует использование актуального стека Java-разработки, микросервисных паттернов и контейнеризации.

## 🛠 Технологии
* **Java 21**
* **Spring Boot 4.1.1** (Web, Data JPA, Security, Cache)
* **PostgreSQL** — основная реляционная база данных
* **Redis** — кэширование данных (ускорение запросов)
* **Kafka** — брокер сообщений (асинхронное взаимодействие)
* **Liquibase** — версионирование схемы БД (миграции)
* **Docker & Docker Compose** — полная контейнеризация инфраструктуры и приложения
* **MapStruct & Lombok** — генерация мапперов и boilerplate кода
* **Swagger (OpenAPI)** — автодокументация API

## ⚙️ Как запустить (Локально)

Благодаря Docker Compose, поднять всё приложение вместе с инфраструктурой можно одной командой.

1. Убедитесь, что у вас установлен Docker и Docker Desktop.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/твое-имя/taskflow.git
3. Выполните команду в корне проекта:
   ```bash
   docker-compose up -d --build

После сборки приложение будет доступно на порту 8081.
